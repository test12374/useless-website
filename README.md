## Uploading to ChatGPT
1. Download the `Useless-2.0.6-upload.zip` release asset.
2. In ChatGPT on the web, open the supported workspace's plugin management area.
3. Choose **Add / Upload plugin** and select the ZIP, if that upload option is available to your workspace.
4. Follow ChatGPT's prompts to review and install it.

**Important:** GitHub hosting does not itself install a plugin in ChatGPT. Upload availability is controlled by ChatGPT and may require an eligible workspace with upload permission. A personal Free account may not have this upload option. This package is the plugin source/export, not a public ChatGPT install link.
